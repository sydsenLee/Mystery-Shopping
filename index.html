Getting started

If the delegates used Google Forms: click Import csv file and choose the results file you downloaded from Google Forms.

If the delegates did not use Google Forms, or you want to add more dealerships by hand: type the dealership name in the box below and click Add dealership.

Use either option below. Each form answer becomes a dealership. Answers already imported are skipped, so you can import again whenever new forms arrive.

The easiest fix is to use your form's questions in this app. Dealerships already in the app will lose their answers, so only do this before you start or after Clear all dealerships.
